模型—市场背离 / 领先性

这里观察“底层市场状态”和“指数价格”是否暂时走向相反方向。模型下降而指数上涨 = 顶部风险背离；模型上升而指数下跌 = 底部修复背离。背离不是见顶/见底确认，而是价格尚未完全承认底层环境变化的观察信号。

历史相似形态拟合 · Analog Model

把当前综合评分、评分变化、指数短中期走势、波动、趋势效率与当前背离状态，与历史逐日状态做标准化近邻匹配。它回答“历史上最像现在的阶段后来走了多久、多久上破/下破、支撑和压力大约在哪里”。相似度不是上涨/下跌概率；当前历史评分仍含重建成分，所以本区只作探索研究。
