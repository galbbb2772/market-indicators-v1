# Market Regime Lab V2

> **当前版本：Market Model V2（Pruned 20）。旧版“28 指标 V1”说明已经废弃。**

这是一个**独立于交易策略本身**的美股市场环境、风险状态与模型—价格背离研究面板。

> 目标不是直接预测明天涨跌，而是把市场内部已经发生、但价格可能尚未充分反映的风险、流动性、情绪、信用、宏观和结构性变化量化出来，并持续观察市场何时重新定价这些变化。

## 当前系统

- **82 个指标数据池**，不删除研究信息，只区分是否拥有“投票权”
- **20 个 Active**：真正进入总市场评分的核心、相对独立指标
- **19 个 Context**：用于解释、交叉确认和研究，但不重复进入总评分
- **43 个 Archive**：低频、待接数据、重复代理或当前信息增量不足的指标
- **Level / D1 / D2**：当前状态、变化动能与动能加速度
- **基础重要性 + 今日重要度**：基础权重固定，今日重要度随市场状态每日变化
- **总市场综合评分 0–100**：描述当前市场环境，不等同于涨跌预测
- **四灯风险区间**：绿 / 蓝 / 黄 / 红，表示风险环境与常规策略执行强度参考
- **市场结构 + 波动状态**：上行 / 下行 / 区域震荡，以及低 / 常态 / 高波动
- **超跌 / 均值回归状态**：红黄区结合综合 D1 / D2 判断修复与反转确认
- **三大指数联动**：S&P 500、Nasdaq、Dow Jones
- **2016 至今历史探索**：可按日 / 月 / 年及自定义日期区间查看评分与指数表现
- **背离 / 领先性研究**：研究模型与价格的 5D / 10D / 20D 背离，以及 0 / 1 / 3 / 5 / 10 / 15 / 20 个交易日 Lead/Lag
- **Leave-One-Out Ablation V2**：每次刷新逐项拿掉 Active 指标，同时检查全历史与 2022 至今的时间外样本（OOS）
- **每日自动刷新 + 手动即时刷新**

## 为什么从 31 个 Active 压缩到 20 个

V2 不追求“指标越多越好”。如果多个指标实际上在重复计算 VIX、科技波动、信用压力或同一个复合指标，它们同时进入总分会制造虚假的“多重证据”。因此当前版本优先保留独立信息量，把派生复合项、无明确方向项和较慢背景变量移到 Context / Archive。

### 第一轮结构性去重：31 → 24

移出 Active：

`market_move_speed`、`market_bias`、`largecap_panic`、`ghost_story_density`、`inventory_cycle`、`usd_credit`、`fiscal_deficit`

这些项目没有从 82 指标池删除，只是不再重复参与总评分。

### 第二轮 OOS 消融：24 → 20

Ablation V2 使用 **2016–2021 训练段 + 2022 至今时间外样本**交叉检查。四个指标在完整历史与 OOS 中同时表现为信息重复 / 风险分层拖累，因此降为 Context：

`quant_crowding`、`cross_asset_correlation`、`rate_cycle_sensitivity`、`credit_cycle`

这次调整后，2022 至今样本中的风险分层明显改善：高评分与低评分组未来 20 日最差路径的差距由负值转为约 **+1.59 个百分点**；低评分组未来 20 日平均最差路径约 **-3.40%**，高评分组约 **-1.81%**。同时 5% 尾部风险发生率差距约 **21.6 个百分点**。这些仍是研究结果，不代表收益保证。

## 核心解释

### 综合评分

综合评分高低首先表示**市场环境的稳定 / 压力程度**，而不是“高分一定涨、低分一定跌”。

- 🟢 **绿灯 65–100**：低风险 / 支持环境
- 🔵 **蓝灯 55–64.99**：中性偏支持
- 🟡 **黄灯 45–54.99**：过渡 / 谨慎区
- 🔴 **红灯 0–44.99**：高风险观察区

红灯并不等于未来一定继续下跌。它更应理解为风险高、后续不利波动可能更大，同时也可能进入超跌 / 均值回归机会区。

### 模型—价格背离

- **模型下降 + 指数上涨** → 顶部风险背离
- **模型上升 + 指数下跌** → 底部修复背离
- **模型上升 + 指数上涨** → 上涨确认
- **模型下降 + 指数下跌** → 下跌确认

背离是风险 / 修复线索，不代表顶部或底部已经确认。

### Ablation Test

Ablation V2 不再只看一个样本内目标函数。它逐项移除 Active 因子，并同时比较：

- 全历史风险分层
- 2022 至今 OOS 风险分层
- 低分 vs 高分未来 20 日最差路径差
- 5% 尾部风险发生率差
- 评分噪声 / 分布宽度
- 同一 Bucket 内 5 日变化的重复相关性

**注意：历史仍包含 reconstructed history，并非完整 publication-time point-in-time 数据。** 因此 Ablation 是 pruning evidence，不是自动真理；模型不会因为一次样本内结果就机械删除重要的宏观 / 信用因子。

## 网站结构

- `docs/index.html`：主仪表盘与交互界面
- `docs/data/current.json`：网站当前数据、历史序列与 ablation 结果
- `update_data.py`：每日指标抓取、计算、市场状态与历史研究
- `ablation_runner.py`：逐项 Leave-One-Out + OOS 消融测试与重复性诊断
- `history_builder.py`：三大指数历史数据构建
- `patch_divergence_ui.py`：背离 / 领先性页面构建逻辑
- `indicator_config.json`：82 个指标定义、重要性与基础属性
- `market_model_v2.json`：Market Model V2 Active / Context / Archive、权重与观察周期
- `manual_inputs.json`：低频 / 暂时人工输入
- `.github/workflows/daily_update.yml`：自动更新、消融测试、历史构建与 GitHub Pages 部署

## 更新机制

1. **自动更新**：按纽约时区每日定时运行。
2. **手动更新**：GitHub Actions → `Daily Market Indicators` → `Run workflow`，可随时刷新最新市场数据并重新部署网站。

每一次刷新都会重新执行 Ablation V2。低频、月频、季度数据会每日检查，但只有原始数据源出现新值时才更新；不会人为制造日度变化。

## 历史与验证说明

- 三大指数价格历史：**2016 至今**
- 综合评分历史：从可稳定重建的历史区间开始
- 历史评分包含 reconstructed history 与之后的 live-recorded 数据
- 部分宏观历史仍可能存在“观察日期 ≠ 实际发布时间”的 point-in-time 问题
- Lead/Lag、背离、灯号阈值、Ablation 排名等仍属于研究框架，不能直接解释为未来收益保证

## 数据源与代理

系统使用公开市场与宏观数据源，包括 Yahoo Finance、FRED 及其他公开数据接口。部分暂时无法取得稳定直接数据的指标会使用公开代理变量，并在数据质量字段中标记为 `proxy`；需要新闻文本、13F、财报、社交讨论或债券发行明细的数据会保留为待接入，而不是伪造实时值。
