# Factor Map V1 — Study Specification

Status: **research-only / diagnostic-only**. This study must not change production weights, thresholds, active/context/archive membership, traffic-light rules, or execution rules.

## Goal

Compress the validated bottom-level indicator universe into a smaller set of economically interpretable, redundancy-aware information families and test whether each family carries independent information about forward SPY returns.

## Input

- `update_data.py` reconstructed `series_store`, captured through the existing `ablation_runner.run_update_and_capture()` path.
- `indicator_config.json` metadata and `market_model_v2.json` role metadata.
- SPY close history generated by the same run.
- Minimum history: 252 aligned observations and >=10 distinct score values.
- Only indicators with `impact_polarity` in {-1,+1} enter predictive family composites. `impact_polarity=0` remains descriptive/context only.

## Frozen family taxonomy

The taxonomy is semantic and fixed before results are read. The runner may fall back to category/id-keyword rules only to place newly added indicators; all placements are reported.

## Orientation

For every directional indicator, build a *supportive-state score*:

- polarity +1: supportive = score
- polarity -1: supportive = 100 - score

Thus higher family score always means a more supportive/healthy current state. The sign of family IC then determines interpretation:

- positive IC -> continuation-style information
- negative IC -> mean-reversion-style information
- unstable/mixed -> regime-dependent / descriptive

No sign is flipped to improve results.

## Within-family redundancy compression

Within each family:

1. compute Spearman correlation of 5-trading-day score changes;
2. connect indicators when |rho| >= 0.85 and pair n >= 120;
3. connected components are redundancy components;
4. average supportive scores inside each component;
5. family score = equal-weight average of redundancy components.

This prevents duplicated indicators from receiving multiple votes.

## Primary tests

For every family report:

- 5D / 10D / 20D Spearman IC;
- quintile Q5-Q1 forward-return spread;
- eras: 2017-2019, 2020-2021, 2022-present;
- regimes: above/below MA200 and RV20 >=20 / <20;
- 252-session rolling 10D IC;
- overlap-phase robustness at 10D;
- Leave-One-Year-Out univariate linear prediction vs train-mean baseline;
- full-sample and 2022+ partial Spearman after controlling for all other family factors;
- family inter-correlation on 5D factor changes.

## Multivariate family ablation

Use a fixed ridge regression (`alpha=10`) in Leave-One-Year-Out evaluation. Features are training-set z-scored family scores. Compare:

- full family set;
- full family set minus one family.

Report OOS MSE change only. No alpha tuning, feature selection, or post-result sign changes are allowed.

## Interpretation guardrails

- Historical reconstruction is not perfectly point-in-time for every macro series.
- A good historical family is not automatically promoted to production.
- Family labels do not imply causal mechanisms.
- Redundancy compression is for research interpretation only.
- Any future production change requires a separate preregistered OOS decision.
